=== speech worker --help ===
usage: speech worker MODEL [options]

Loads MODEL, warmed up unless --no-warmup, adds the voices of --add-voice, and serves it over the worker protocol
4: one JSON object per line on stdin and on stdout, and nothing else on stdout. speech.cpp's
docs/worker.md gives the messages. A request option given as a flag is the default of every request that does not
set it, in place of the model's own.
MODEL is a model file (.gguf), or the NAME[:TYPE] of one in `speech models`, fetched the first time it is used.

  --add-voice NAME=FILE       add a voice from a voice file or a WAVE file before the first request; repeatable
  --device NAME               auto (the first GPU, or the CPU without one), gpu, cpu or a name `speech devices` lists
  --threads N                 the CPU's threads, 1 or more; the machine's performance cores unless given
  --no-warmup                 skip the short request that compiles a GPU's kernels before the first one
