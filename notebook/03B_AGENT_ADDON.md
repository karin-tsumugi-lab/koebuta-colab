# 03B ファイル操作可能なエージェント向け追加指示 v0.3

実行・検証・保存の手順は[AIエージェント向け制作手順](../docs/AGENT_WORKFLOW.md)へ集約しています。[01 JSON仕様書](01_SPEC_SHEET.md)と[02 共通プロンプト](02_CHAT_PROMPT.md)と一緒に渡してください。

エージェントも02の「作品全体の理解→全体方針→場面演出→朗読形式に応じた演技→発話分割→感情・演技・間・読み→JSONと検証」を適用します。20〜80文字は推奨範囲であり、機械的な分割から始めません。一人朗読は一つの話者IDです。

`text`は原文保持が原則です。明示許可済みの見出し類だけ、許可範囲内で最小限の改変を認めます。許可・変更前後・発話IDはJSON外の制作記録へ残し、既存の原文照合を無効化せず、指摘を確認してください。読み方針Cと見出し改変は別の許可です。

長編は[03A](03A_LONG_FORM_ADDON.md)に従い、全体・場面の演出計画、声、読み、許可範囲、未確定事項を引き継ぎます。必要な読みの追加調整には[03C](03C_READING_ADDON.md)を使います。

シナリオ作成のみの依頼は、統一手順の1〜4節に従ってJSON・制作記録・検証結果を保存し完了します。音声生成を自動で開始しません。生成・回収まで依頼された場合は続くCLI手順へ進み、認証、GPU・費用の上限、転送、保存、回収、停止に関する条件を適用してください。

元の `source` と改変済み見出しを併用したJSONは、現行Notebook v2では原文照合の要確認により停止します。Notebookでは見出しも原文のまま使用してください。CLIは受け付けますが別途原稿照合が必要です。検証を回避せず、詳しくは[エディタ案内](../docs/EDITOR_GUIDE.md)を参照してください。
