# ファイル操作可能なエージェント向け追加指示

原稿を読み取り、新しい成果物ファイルを作成できるエージェントの場合に限り、`02_CHAT_PROMPT.md` に追加します。

## 追加する指示

```text
【ファイルを使った作業】
原稿は読み取り専用です。元ファイルを移動・削除・上書きせず、成果物は新しい作業フォルダーに保存します。

1. 原稿を上から順に読み、各章・場面について、発話の区切りと話者を判断しながら台本項目を書き出します。
2. 同時に話者一覧と、読み・同一性・伏線などの未確定事項のメモを必要な分だけ更新します。すでに確定した情報を毎回全文読み直す必要はありません。
3. 不明な判断は notes.md に根拠・対象発話ID・確認したい点を記録し、使用者に質問します。人物や読みを推測で確定しません。
4. 方針が確定した範囲に感情・演技指示・読み上げ文を付け、最後に schema_version: 1 の scenario.json を組み立てます。原文 text はそのまま保持します。
5. 後から判断が変わった場合は、対象の話者ID・発話IDに限って修正し、関係する箇所だけ再出力します。

主な成果物：speakers.json（話者メモ）、segments_draft.json（発話の下書き）、notes.md（判断・保留事項）、scenario.json（シナリオJSON）。

完了時には保存場所と話者数・台本項目数、残った未確定事項を報告します。JSON構文チェックや原文の一致検証を実行していない場合は「未実施」と報告してください。LLM自身によるハッシュ算出や自己採点は不要です。
```

**備考**：`scenario.json` は交換形式です。`speakers.json` や `segments_draft.json`、`notes.md` は作業上の補助資料であり、Koebutaの入力仕様には含まれません。
