# Koebuta Notebook v2 — 生成専用WebUI

シナリオJSONから、Irodori-TTSを使って朗読音声を作成するGoogle Colab用Notebookです。作品の読み込み、声の設定、音声の生成・比較試聴・採用、完成WAVの出力を行えます。

シナリオJSONは読み取り専用です。本文・読み・話者・感情・演技・分割位置を編集する場合は、HTML版のScenario Inspectorなどで修正し、読み込み直してください。WebUIで変更した声の説明や生成設定は、元JSONへ書き込みません。

## 利用前に

原稿・参照音声・生成物を利用、保存、公開する権限があることを確認してください。本人の同意のない声の複製・なりすましや、人を欺く目的での利用は行わないでください。

Koebuta、Irodori-TTS、使用モデルには、それぞれのライセンス・利用条件が適用されます。利用前に、リポジトリのライセンス、第三者の権利表示、モデルカードを確認してください。

本NotebookはGradioの外部WebUIを使用します。Google Colabには利用形態やプランに応じた制限があります。実行前に[Colab公式FAQ](https://research.google.com/colaboratory/faq.html?hl=ja)と利用規約を確認してください。有料プランでも、無制限の利用を保証するものではありません。

共有URLとログイン情報は公開しないでください。Colabの一時領域にあるファイルは、ランタイム終了などで失われる場合があります。

## 起動

1. Google ColabでGPUランタイムを選び、セルを上から順に実行します。
2. Google Driveを使う場合だけ、Driveマウント用セルの`USE_DRIVE`を`True`にします。
3. WebUI起動セルで、Irodori-TTSのモデルをGPUへ読み込みます。初回は取得・読み込みに時間がかかります。準備状況はセルの出力に表示されます。
4. 準備完了後に表示される共有URLを開き、同じセルに表示されたユーザー名・パスワードでログインします。

## 1. 作品の読み込み

次のいずれかで作品を読み込みます。

- **作品ZIP**：`scenario.json`と参照WAVをまとめたZIP。作品フォルダを一つ包んだ形にも対応します。
- **シナリオJSON単体**：JSONだけを読み込みます。参照WAVは付属しないため、自動生成または手動割り当てを利用してください。
- **Google Drive作品フォルダ**：マウント済みDrive内の、`scenario.json`を含む作品フォルダを指定します。

ファイルのアップロードとフォルダ指定が両方ある場合は、アップロードを優先します。

「作品を読み込む」を押すと、構造を検証し、実際の生成単位・話者・原文を一覧へ表示します。`t010#1`、`t010#2`のような表示は、一つの発話が複数のTTS片に分かれていることを示します。

読み込み成功は、読みや配役、生成音声の品質を保証するものではありません。

## 2. 声の設定

人物一覧には、話者ID・名前・声設定の有無を表示します。指定された参照WAVがある場合は、その音声を優先します。

WAVが未設定でも生成できます。複数回話す人物では、適切な長さの通常台詞を選び、感情・演技を付けずに参照音声を先に作成します。その声を使って本文を生成します。一度しか話さない人物や、適切な台詞が見つからない人物は、参照なしで生成します。

自動選択は文字数などに基づく簡易判定です。声の一貫性や、台詞が参照に適していることを保証しません。必要に応じて参照WAVを手動で割り当ててください。

「声の試作」では、人物の`voice_caption`をもとに声を試せます。説明文は編集でき、試作音声を選択中の人物の参照音声として採用できます。

## 3. 生成・試聴・採用

Seed、Steps、感情・演技の反映などを設定して生成します。🎲ボタンはSeedをランダムに変更します。

「全編生成」は、利用可能な採用済み音声を維持し、不足している音声を生成・採用します。試聴待ちの候補がある場合は、先に採用または破棄してください。

個別に調整したい場合は、生成単位を選んで「新しい候補を生成」を押します。「同じ発話の全片をまとめて操作」を選ぶと、その発話に属する全片を対象にします。

採用済み音声と最新候補を比較試聴し、「候補を採用」または「候補を破棄」を選んでください。候補の生成だけでは、採用済み音声や作成済みの完成WAVは変わりません。

未採用候補は、生成単位につき最新1件です。発話全片の候補更新は、全片の生成に成功したときだけ行います。

進捗表示では、自動参照作成・本文生成・キャッシュ再利用などを確認できます。進捗バーは工程単位の目安で、残り時間やモデル内部の生成ステップを示すものではありません。

## 4. 出力・保存

「完成WAV再結合・出力」で、採用済み音声を原稿順に結合し、完成WAVと個別音声ZIPを作成します。候補を採用し直した後は、再結合してください。

出力作品名は変更できます。空欄では、アップロード名や作品フォルダ名を使用します。保存名には作品名・出力種別・日時が付きます。

例：`桃太郎_完成_20261107_153045_123456.wav`

Drive保存先が空欄でも、生成・試聴・出力は利用できます。出力後のファイルをダウンロードしてください。

「作業状態を保存」では、完成前でも採用音声・候補・声の設定・生成条件を保存できます。再開時は同じ作品を読み込み、保存先を指定して「保存状態を復元」を押します。互換性のない作品・モデル構成では復元できません。

保存先は元作品フォルダとは別の、作品専用フォルダにしてください。Drive外への保存はローカル一時保存であり、ランタイム終了後の保持を保証しません。

## 音声と保存についての注意

短い発話、悲鳴、固有名詞、難読漢字、特殊なルビは、読み飛ばしや誤読、不自然な発音が生じる場合があります。完成音声と個別音声を試聴し、話者・読み・感情・つなぎ目・末尾の欠落を確認してください。

採用済みの過去音声は保持します。通常の再利用キャッシュは件数を制限し、不要になった管理対象ファイルを整理します。履歴を含む保存量は、採用し直した回数に応じて増えます。

電子透かしの有無や検出結果を、権利・出所の唯一の証明にしないでください。出所の確認が必要な場合は、個別WAVと生成条件も保管してください。

終了前に、必要な完成WAV・個別音声ZIPをダウンロードし、継続する作業は保存してください。
