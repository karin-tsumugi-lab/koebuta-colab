# Colab・Colab CLIの利用条件

公式資料の確認日：2026-11-02。利用時にはリンク先の最新の条件を確認してください。

## CLIを使う場合もColabの規約が適用されます

[公式Colab CLI](https://github.com/googlecolab/google-colab-cli#legal--privacy) は自動処理やAIエージェント連携を想定したツールですが、利用にはColabの利用規約とGoogleのプライバシーポリシーが適用されます。CLIのソフトウェアライセンスと、Colabサービスの利用条件は別です。

[Colab追加利用規約](https://research.google.com/colaboratory/tos_v5.html) は、FAQの制限行為・利用上限への同意も求めています。KoebutaはGoogleによる個別の利用承認や、アカウント停止・処理中断が起きないことを保証するものではありません。

## 無料枠・CU残高なしでの追加制限

[Colab公式FAQの制限行為](https://research.google.com/colaboratory/faq.html#limitations-and-restrictions) では、無料で動作し正のCU残高がない管理ランタイムについて、SSH等の遠隔操作や、Notebook UIを迂回して主にWebUIから操作する利用などを追加の禁止対象とし、予告なく終了する場合があると説明しています。有料プランを購入し正のCU残高を維持することで、その種の追加制限を解除できると案内されています。

KoebutaのNotebook版は外部Gradio UIを使います。その運用は無料・CU残高なしの管理ランタイムで勧めません。CLI版の自動運用も、無料枠の制限を回避する方法として紹介・利用しないでください。公式FAQはCLIによるすべての処理を一律に禁止すると記しているわけではありません。実際の操作と利用形態に適用される条件を確認してください。

## 有料でも残る条件

有料プランでも、全管理ランタイムに共通する禁止行為やリソース制限は残ります。FAQにはdeepfake作成、複数アカウントでの制限回避等が禁止行為として列挙されています。原稿・参照音声の権利や本人の同意を確認することに加え、Colab側の禁止事項にも従ってください。声の合成・複製の個々の用途がGoogleから許可されたとKoebutaが判断するものではありません。

[リソース制限](https://research.google.com/colaboratory/faq.html#resource-limits) は変動し、希望GPUや稼働時間は保証されません。有料でもCUを使い切ると無料枠のポリシー・制限に戻ります。生成途中の中断に備えて成果物を回収し、制限を回避するための複数アカウント利用や偽の活動による切断回避は行わないでください。

アカウントの共有や、第三者へColabへの直接・間接のアクセスを販売・貸与・提供する行為も追加利用規約で制限されています。コードの公開と、Colabアカウント・認証情報・ランタイムへのアクセスの提供を混同しないでください。
