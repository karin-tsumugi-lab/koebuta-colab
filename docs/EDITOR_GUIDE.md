# Koebuta Scenario Inspector v0.1.6

単一HTMLでシナリオJSON、話者、読み上げ文、感情、演技、間、参照WAVを編集・確認するツールです。音声合成は行いません。参照WAVの試聴はできます。

## 開く・編集する・保存する

`Koebuta_Scenario_Inspector_v0.1.6.html` をブラウザーで開きます。作品フォルダーを扱う機能にはFile System Access APIを使います。画面はChrome/Edgeを案内しますが、添付レビューでは `file://` 直接起動と実OSのディレクトリ選択による読み書きは未試験です。ブラウザー上の模擬操作試験と区別してください。

作品フォルダーには `scenario.json` を置き、参照WAVは `voices/…wav` 等の相対パスで管理します。フォルダーを開かずJSONだけを開く方法もあります。選んだ参照WAVの追加・変更がある場合、JSON単独では音声実体を保存できないため「フォルダ保存」または「ZIP出力」を使ってください。

フォルダー保存では使用中の参照WAVとJSONを保存します。別フォルダー保存では必要な参照WAVもコピーします。保存完了後はUndo/Redo履歴がクリアされます。Undoは保存前の編集履歴として扱い、ディスク上の世代バックアップの代用にしないでください。

検査エラーがあっても、確認のうえで編集中JSONとして保存できる実装です。「保存できた」ことは「音声生成できる」ことを保証しません。保存後は再度開いて本文、読み、話者、演技・感情、間、WAVの対応を確認してください。

## TTS分割と原文

TTS分割は原文 `text` や原稿全文 `source` を切り刻まず、`koebuta_tts_parts` に読み上げ文の片を保存します。片の連結値は発話全体の `tts_text` と一致する必要があります。片を編集すると全体の `tts_text` も連動します。分割によって親の台本行数が増えるわけではありません。

通常結合で後続行の未知フィールドを安全に保持できない場合は処理を拒否します。強制結合は元データを `koebuta_merge_backup` に残しますが、発話ごとの話者・感情・演技・中間の間がそのまま維持されるとは限りません。結果を確認してください。

## 生成側への受け渡し

| HTMLの保存情報 | 正式Notebook v2 | CLI v1.0.1 |
| --- | --- | --- |
| `koebuta_settings` | 読み込み時と生成計画へ反映 | 自動取り込みなし。別設定JSONを指定 |
| 話者 `reference_wav` / 共用WAV | 作品内の参照WAVを解決 | 別設定JSONの `voices` と `speakerVoices` 等で指定 |
| `koebuta_tts_parts` | 発話ごとの生成片として使用 | 指定された片の境界を利用しない |
| `tts_text` | 読み上げに使用 | 読み上げに使用。ただしCLIの分割検査・規則に従う |
| 発話 `pause_after_ms` | 個別の間として使用 | 個別の間として使用。CLI許容範囲は0～10000ms |

HTMLの生成設定画面にある「将来のCLI用拡張」という文言は、CLI v1.0.1で対応済みという意味ではありません。`reading_mode` → `reading`、`use_emotion` → `emotion`、`use_acting` → `acting`、`narrator_emotion` → `narratorEmotion`、`default_pause_ms` → 秒単位の `pause` のように設定体系が異なります。設定の丸ごとコピーはできません。自動変換や無損失互換は未提供です。

正式Notebookの操作は [v2操作ガイド](../notebook/NOTEBOOK_V2_GUIDE.md) を参照してください。v1の内蔵編集画面を前提にした過去の操作説明は旧版資料として扱います。

[Fast版](../fast/README.md) も `koebuta_settings`・参照WAVパス・TTS分割境界の自動取り込みに対応しません。単一話者だけを対象とし、参照音声は `--ref`、分割と短文結合はFast版独自の規則を使います。空行情報は結合を防ぐために使いますが、Notebookと同じ空行休止時間を自動適用するわけではありません。

## 保存・検査の限界

元ファイルの複製を残し、同じ作品フォルダーを別アプリで同時に更新しないでください。通常の保存例外には復旧処理がありますが、電源断やブラウザー強制終了時に複数WAVとJSONを一括で戻せる保証はありません。排他制御・電源断対策の追加実装は今回の文書作業に含めません。

原稿照合は順序付き部分照合であり、全文の欠落・重複がないことの証明ではありません。WAVは構造を検査し、64MiB以下では利用可能なAudioContextでデコードを試みます。大容量WAVの音声内部までの正常性は保証しません。

今回の整理ではHTMLのコードと添付レビューを静的に照合しました。レビュー資料にあるテスト成功件数は過去の実施報告であり、今回の再実行結果ではありません。
