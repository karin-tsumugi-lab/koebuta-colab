確認日 2026-11-13。Notebook v2、CLI、Inspector、Fastの感情IDを34種類（neutral、従来14種類、追加19種類）へ統一。位置指定と除外対象を含めた公式絵文字45種類を台帳に収録した。v1 Notebookは旧版として保持する。

- `python tools/build_notebook_v2.py` は成功。正式版とprototype別名の両方を再生成し、全コードセルを構文検査した。
- `python -X utf8 -m unittest discover -s cli -q` は30件成功。
- `python -X utf8 -m unittest discover -s fast/tests -q` は18件実行、17件成功、音声結合の依存ライブラリ不足で1件skip。
- `.venv-v2/Scripts/python.exe -X utf8 -m unittest test_notebook_v2 test_notebook_v2_ui test_inspector_p0 test_v2_emoji -q` は26件成功。Gradio解析送信を無効にして実行。終了時に既存のunclosed event loop ResourceWarningが出る。
- `node test_inspector_emoji.cjs` は成功。編集後の再描画で元の入力要素が外れても、保存したカーソル位置へ効果音を挿入できる。
- 公開対象の `cli/irodori_generate.py` に8発話のシナリオを指定したdry-runは成功。参照音声のSHA256、パラメータ、生成文字列を含む8件のrequestsが、試聴済み実行のplan.jsonと完全一致した。
- READMEのローカルリンクに欠落なし。
