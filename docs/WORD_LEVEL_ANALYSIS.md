# 語単位ラベルによる ModernBERT 特徴量の誤読予測評価（2026-11-18）

## 1. 結論

**通常文（散文）において、漢字表記とルビ置換文の特徴量コサイン類似度（`cos_cond` / `cos_bb`）から、誤読しやすい漢字を高精度に予測できることが語単位データで実証されました。**

- **A条件・通常文のみ（n=47, 誤読26 / 正読21）**:
  - `cos_cond` の AUROC = **0.8846**（`cos_bb` = **0.8791**）
- **通常文 + 対照KO（n=53, 誤読26 / 正読27）**:
  - `cos_cond` の AUROC = **0.9017**（`cos_bb` = **0.8932**）
- **全70語（漢詩17語を含む, 誤読43 / 正読27）**:
  - `cos_cond` の AUROC = **0.8372**（`cos_bb` = **0.8122**）

## 2. 最適閾値での分離結果（通常文 + KO, n=53）

- **`cos_cond <= 0.8327` を「ルビ展開（危険）」、`> 0.8327` を「漢字維持（安全）」とした場合**:
  - **正解率（Accuracy）**: **88.7%（47/53）**
  - **誤読捕捉（TP）**: **23/26（88.5%）**
  - **見逃し（FN: 誤読なのに漢字維持）**: 3/26（`懇ろ` 0.8711, `豊頬` 0.9152, `副い` 0.9295）
  - **過剰警告（FP: 読めるのにルビ展開）**: 3/27（`袁` 0.6816, `賤吏` 0.7687, `慟哭` 0.7702）
  - **対照KO（日常語 6語）**: **6/6 すべて漢字維持（誤警告ゼロ）**

- **`cos_bb <= 0.8146`（ModernBERT バックボーン単体）の場合**:
  - **正解率（Accuracy）**: **83.0%（44/53）**
  - **誤読捕捉（TP）**: **23/26**、**見逃し（FN）**: 3/26、**過剰警告（FP）**: 6/27

## 3. 残る課題と設計への示唆

1. **「読める漢語を訓読みする / 訓読みを音読みする」タイプのすり抜け**
   - `懇ろ`（ねんごろ → こんごろ）、`副い`（そい → ふくい）など、漢字単体としては一般的で ModernBERT 上では仮名と近い表現になる語は、`cos_cond` が高くても TTS が音訓を取り違えるケースがある。
   - **対策**: 送り仮名を伴う和語（訓読み）で誤読リスクがあるものや、音訓両読の難読語については、特徴量閾値をやや保守的に取るか、軽量な辞書／ルール（送り仮名付き漢字の扱い）で補うとさらに偽陰性を減らせる。
2. **漢詩・白文（17語）の扱い**
   - 漢詩は送り仮名・返り点なしの白文を日本語訓読するため、17/17 すべてが原文のままでは誤読された。
   - 漢詩・漢文の訓読パートは特徴量判定に頼らず、**無条件でルビ（訓読文）へ展開する**のが妥当。
3. **次の実験へ（交差検証と他作品での汎化）**
   - 今回は『山月記』1作品（53語＋漢詩17語）の探索データ上での結果であるため、次は別の作品・日常文（先ほどのアリスの音声で誤読された箇所など）で、`cos_bb` または `cos_cond` の閾値がそのまま汎化するかを検証するのが最優先となる。

## 4. 独立データでの汎化検証：アリスの朝の挨拶（19語, 2026-11-18）

`Aratako/Irodori-TTS-v4.1-Small`（rev `2b28324d`）のテキストエンコーダ＋プロジェクタ＋`text_norm` をローカルで厳密再現（`t01a 隴西` で `cos_bb=0.806662`, `cos_cond=0.820468`, `l2_cond=10.0827` が小数点以下6桁まで完全一致）し、日常文 4 発話・19 語（誤読 2 語：`昨夜`, `夜更かし`、正読 17 語）を計測した。

- **AUROC (`cos_cond`)**: **0.9412**（`cos_bb` も **0.9412**）
- **誤読 2 語のスコア**:
  - `昨夜`（さくや → やくや）: `cos_cond = 0.5658`（19語中 最下位）
  - `夜更かし`（よふかし → よかし）: `cos_cond = 0.7314`（19語中 4番目）
- **『山月記』の閾値（`cos_cond <= 0.8327`）のそのままの適用結果**:

  - **漢字維持（TN）**: **13 / 17**（過剰展開は `主人様` 0.6760、`本日` 0.7215、`用意` 0.7930、`紅茶` 0.7988 の 4 語のみ）
